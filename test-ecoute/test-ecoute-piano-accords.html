    Pour un test fiable

    • Joue les notes d'un accord ensemble, puis laisse sonner une demi-seconde.
    • Le résultat arrive environ 0,4 s après l'attaque : l'analyse attend d'avoir entendu la note entière.
    • Attends que le son s'éteigne avant l'accord suivant.
    • Les notes très graves (sous Do3) sont les plus difficiles à séparer quand elles sont jouées ensemble.
